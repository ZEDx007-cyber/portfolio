# Ishan Kundu — Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Live site

https://zedx007-cyber.github.io/portfolio/

## Run locally

Open `index.html` in a browser. The page uses Google Fonts for typography; the rest of the site is served from this repository.

## Project files

- `index.html` — portfolio content and page structure
- `styles.css` — responsive layout, colors, and animation
- `script.js` — updates the footer year
- `assets/ishan-kundu.jpg` — profile image
- `.github/workflows/deploy-pages.yml` — deploys the site to GitHub Pages when changes are pushed to `main`
